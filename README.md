# 📄 Al-al-Bayt File CONVERTER

أدوات تحويل ملفات PDF مجانية تعمل 100% في المتصفح — بدون رفع ملفات لأي خادم.

## المميزات
- 🔗 دمج ملفات PDF
- ✂️ تقسيم PDF
- 🗜️ ضغط PDF
- 🖼️ تحويل صور إلى PDF
- 🔒 خصوصية تامة (Client-Side فقط)

## التقنيات
- HTML / CSS / JavaScript
- [pdf-lib](https://pdf-lib.js.org/)

## التشغيل
افتح `index.html` مباشرة، أو انشر على GitHub Pages.

## النشر على GitHub Pages
1. ارفع الملفات إلى المستودع
2. Settings → Pages → Branch: `main` / root
3. الموقع سيكون على: `https://<username>.github.io/<repo-name>/`
